# Cybersecurity Lab Setup – Week 1

## Project Overview
This project is part of the Networkwalks Cybersecurity Internship.

The objective is to prepare a virtual cybersecurity lab environment using Kali Linux and Oracle VirtualBox for practical cybersecurity learning.

## Tools Used
- Kali Linux
- Oracle VirtualBox

## Project Objectives
- Understand the basics of virtualization.
- Set up a cybersecurity learning environment.
- Install and configure Kali Linux.
- Prepare for practical cybersecurity exercises.

## Implementation
1. Set up Oracle VirtualBox.
2. Prepared the Kali Linux environment.
3. Configured and started Kali Linux.
4. Verified that the environment was working.

## Screenshots
Screenshots of the completed lab setup and Kali Linux environment are included in this repository.

## Learning Outcomes
- Gained practical experience with virtualization.
- Learned about the Kali Linux environment.
- Improved understanding of cybersecurity lab preparation.
- Prepared for future cybersecurity practical exercises.

## Conclusion
This project provided practical experience in preparing a virtual cybersecurity lab using Kali Linux and Oracle VirtualBox. It is an important first step in developing practical cybersecurity skills.
